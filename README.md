# LiteratureReview

本仓库用于持续收集、整理和总结与居民健康相关的地理学研究文献。

## 研究目标

本项目关注地理环境、城市空间、社会经济发展与居民健康之间的关系。当前以一组跨学科期刊为主要文献来源，定期追踪新发表的研究，并逐步建立可检索、可筛选和可复用的文献库。

重点关注的问题包括：

- 居民所处的自然环境、建成环境和社会环境如何影响健康？
- 收入、教育、就业、住房和公共服务等社会经济条件如何影响居民健康？
- 城市化、区域发展和社会经济转型是否会加剧或缓解健康不平等？
- 健康相关的空间差异如何形成，并如何进行测量和解释？
- GIS、遥感、空间统计和城市大数据能够如何支持健康研究？
- 哪些环境暴露和城市干预具有重要的公共健康意义？

## 主题范围

收集范围包括但不限于以下主题。

### 健康行为与生活方式

- 睡眠时长、睡眠质量、失眠和昼夜节律
- 饮食行为、食物环境和营养健康
- 体力活动、步行、骑行和久坐行为
- 日常出行、生活方式和健康行为差异

### 生理与心理健康

- 心血管疾病、呼吸系统疾病和代谢性疾病
- 慢性病、传染病和疾病风险
- 心理健康、压力、焦虑和抑郁
- 主观幸福感、生活质量和健康不平等
- 老年人、儿童和其他易感人群的健康

### 社会经济发展与健康不平等

- 收入、财富、教育和职业差异
- 就业稳定性、工作环境和劳动条件
- 住房条件、住房负担和居住隔离
- 城乡差异、区域发展和城市化
- 社区资源、公共服务和医疗服务可达性
- 社会脆弱性、贫困和环境正义
- 社会经济转型、人口流动和健康不平等

### 自然环境变化与健康不平等

- 气候变化、极端天气和健康风险
- 空气污染、水污染、噪声污染和暴露差异
- 热浪、寒潮、洪涝、干旱和其他自然灾害
- 绿地、蓝色空间、生态系统服务和自然接触机会
- 环境风险在不同地区、社区和人群之间的不均衡分布
- 环境变化对儿童、老年人、低收入群体和其他易感人群的影响
- 气候适应、环境治理、资源配置和健康公平

### 地理学与空间方法

- 健康地理学和空间流行病学
- GIS、遥感和空间统计
- 建成环境测量和城市形态分析
- 可达性、邻里环境和空间不平等
- 社会经济指标构建、区域比较和空间分异分析
- GeoAI、街景图像、移动数据和城市大数据
- 因果推断、纵向研究和自然实验

## 文献筛选原则

优先收集符合以下条件的文章：

1. 研究问题与居民健康、健康行为或疾病风险直接相关。
2. 关注环境暴露、社会经济条件、空间差异、城市环境或地理情境。
3. 使用地理学、空间分析、流行病学或跨学科方法。
4. 讨论健康不平等、区域发展差异、环境正义或易感人群时，优先纳入。
5. 对理论发展、方法改进、政策制定或城市治理具有参考价值。

与居民健康关联较弱的文章可以保留在原始文献列表中，但不进入核心阅读清单。

## 工作流程

```text
定期收集期刊新文章
        ↓
根据标题和摘要进行初步筛选
        ↓
标记主题、方法、环境暴露和健康结果
        ↓
选取核心文献并撰写阅读笔记
        ↓
按照主题综合研究发现、方法和研究空白
```
